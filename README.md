# 5 Дзырды
1. Название игры - 5 Дзырды
   
2. Суть игры заключается в том, чтобы игрок угадал загаданное слово за 5 попыток. После каждой попытки буквы подсвечиваются разными цветами:
    a) Зеленый - буква стоит на правильном месте;
    b) Желтый - буква есть в слове, но на другой позиции;
    c) Не изменяется - буквы нет в слове.
Игра поддерживает два языка: русский и осетинский, а также три уровня сложности:
    a) Kегкий - 3 буквы;
    b) Cредний - 4 буквы;
    c) Cложный - 5 букв.
Она подойдет для людей, желающих изучить осетинский язык. Если человек угадывает слово на любом из языков, то ему показывается его перевод.

3. Функциональные возможности:
    a) Выбор языка игры (русский / осетинский);
    b) Выбор уровня сложности (легкий / средний / сложный);
    c) Ввод букв с клавиатуры с поддержкой осетинской буквы "æ";
    d) Визуальная подсветка букв (зеленый / желтый);
    e) Возможность начать игру заново или выйти в главное меню.

4. Требования к системе:
    a) Операционная система: Windows 7 или выше;
    b) .NET Framework: версия 4.7.2 или выше;
    c) Среда разработки: Visual Studio 2019/2022.

5. Руководство пользователю:
  Главное меню:
    a) Выберите язык и уровень сложности, нажимая на соответствующие кнопки;
    b) Нажмите "Играть" для начала игры.

   Игровой процесс:
    a) Вводите буквы в строчку с клавиатуры;
    b) Для ввода осетинской буквы "æ" используйте клавишу "ё";
    c) После заполнения строки нажмите Enter для проверки;
    d) Наблюдайте за подсветкой букв: Зеленый - буква на месте, желтый - буква есть в слове, не изменился - буквы нет;
    e) Есть 5 попыток, чтобы угадать слово

   Основные методы:
   a) GetRandomWord - для получения случайного слова с заданной сложностью и языком;
   b) CheckWord - проверяет заполненную строчку. В зависимости от правильности букв и их нахождения раскрашивает их в цвета;
   c) IsCyrillicChar - проверяет символ на то кириллица он или нет.(Не считая "ё", при "ё" ставится осетинская буква);
   d) ChangeLanguage - меняет язык меню при нажатии на соответствующую кнопку.

7. Руководство программиста
Program.cs - Запуск приложения;
FormGame.cs - Главное меню. Изменение языка и сложности. Formgame.cs создает FormPlay.cs с параметрами языка и сложности;
FormPlay.cs - Игровое процесс. Вся логика игры. Создается поле в зависимости от уровня сложности(количества букв в слове), ввод букв, проверка слова и т.д. FormPlay.cs использует WordsRepository.cs для получения случайного слова; 
Word.cs - Модель слова (текст, перевод, сложность, язык)
WordsRepository.cs - Загрузка слов из файлов. WordsRepository.cs использует Word.cs для создания листа объектов Word со своими параметрами.

8. Планы
Создать словарь угаданных слов, отдельную форму со списком слов с их переводом.
Создать подсказки: указать нужные буквы или открыть одну букву в слове.
